# 事前準備

## 必須

- Docker
- VSCode + Dev Containers
- Node.js / npm
- Rust / Cargo
- Git

## 推奨

- Docker Desktop（`host.docker.internal` を使うため）
- MetaMask

## 事前チェックコマンド

```bash
docker --version
npm -v
cargo --version
```

## リポジトリ取得

```bash
git clone --recursive https://github.com/ertlnagoya/Blockchain_IoT_Marketplace.git
cd Blockchain_IoT_Marketplace
```
