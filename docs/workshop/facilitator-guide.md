# ワークショップ進行（講師向け）

## 目的

- 「データ生成 → 商品化 → 購入 → 受け取り」を体験してもらう
- 参加者が自分のデータソース（HUSKYLENS2 / Webcam）で拡張できる状態にする

## タイムライン例（120分）

1. 0-10分: 全体説明
2. 10-35分: 基盤起動
3. 35-65分: サンプル実行
4. 65-95分: スマホ閲覧と購入
5. 95-120分: 発展課題・質疑

## 詰まりやすいポイント

- `host.docker.internal` 名前解決
- MetaMaskアカウント切替
- `ipfs_node` イメージ問題
- Raw data watcher が反応しない

各対処は [トラブルシュート](../operations/troubleshooting.md) 参照。
